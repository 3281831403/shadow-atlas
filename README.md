# shadow-atlas

## 题面

阴影贴图改成图集后，边缘开始漏光：打包时块边界没有对齐到 16/32/64 像素，块边界与像素中心错位，采样时把相邻块的阴影渗了进来；尺寸没有向上取整到对齐边界，奇数宽高的块互相重叠，接缝处出现双重阴影；多级级联的分辨率按级数平均分配，靠近相机的一级分到的分辨率不足，近处阴影发糊；图集增长没有上限，超过硬件允许的最大尺寸后仍继续翻倍，最终分配失败；释放的块只打上 free 标记，空洞永远不会被下一次分配复用，图集很快被撑爆；碎片整理重排后已用面积发生变化，块被放大或缩小，阴影比例失真；过滤模式按整张图集全局保存，多个块先后设置时互相覆盖，近处块被远处块的模式影响；采样坐标越界时直接 clamp 到边界，结果采样到图集里别的块，边缘出现不属于自己的阴影；批量回收在中途失败时，已回收项和未回收项的状态不一致，有的块被标记释放但仍在绘制，有的块已经清空却还能被查询；深度偏移按固定常数给出，不随级联分辨率缩放，远处级偏移过大造成漏光，近处级偏移过小造成自阴影。shadow/atlas.py 是核心，tests/test_atlas.py 15个红。要修的是：对齐打包与尺寸向上取整、按屏幕覆盖率分配级联预算并让深度偏移随分辨率缩放、给图集增长设硬件上限、让空洞真正被复用、碎片整理保持已用面积、过滤模式按矩形记录并对越界坐标报错、批量回收部分失败时保持状态一致。

## 运行方式

```bash
python -m pytest tests -q
```

初始仓库输出恰好 `15 failed`：15 个测试全部命中 `NotImplementedError`，没有 collection / import / syntax error。仅使用标准库与 pytest，离线可跑，无随机、无 sleep。
